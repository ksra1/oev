Outlook Email Validator

✓ This page hosts static assets for an Outlook add-in. It is not meant to be opened directly.

What this is

A client-side Outlook add-in that groups the recipients of the email you're composing by domain, so it's easy to see at a glance whether you're about to send a message to a mix of companies by mistake. All logic runs in your browser inside Outlook; no email content or addresses are ever sent to this server.

Files

  • taskpane.html — the panel that opens when you click the ribbon icon
  • commands.html / commands.js — the send-time confirmation guard
  • dialog.html — the "multiple companies detected" confirmation popup
  • validator-core.js — shared domain-grouping logic
  • manifest.xml — added manually, not part of this repo's build
